# Horizon iOS — сайт

Статическая адаптация главной [playhorizon.dev](https://playhorizon.dev/) под
неофициальный iOS-порт neosay-dev. Сохранены порядок блоков оригинала,
пиксельные сцены, типографика, карточки, мозаика галереи, участники,
двухколоночная таблица и подвал из трёх колонок.

## Просмотр

Открой `dist/index.html` в браузере или запусти из этой папки:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

Главная: `http://127.0.0.1:4174/`. Установка: `http://127.0.0.1:4174/install.html`.
Для статического хостинга достаточно содержимого `dist/`. Установка пакетов и
сборка не нужны. Публикация настроена через `.github/workflows/pages.yml`: push
в `ios-port`, затрагивающий `website/` или сам workflow, публикует `website/dist/`.
Также доступен ручной запуск workflow. Источник Pages в настройках — GitHub Actions.

Адрес GitHub Pages: https://neosay-dev.github.io/horizon-ios/.

## Поведение

- Русский и английский языки, сохранение выбора в браузере.
- Мобильное раскрывающееся меню, закрытие ссылкой, Escape и нажатием снаружи.
- Галерея: увеличение всех плиток, Escape для закрытия, стрелки для переключения.
- На странице установки источник AltStore/SideStore копируется в буфер обмена. Если Clipboard API
  недоступен, поле выделяется для ручного копирования.
- Страница установки: два способа установки с сохранением выбора, FAQ.
- Раскрытие пунктов таблицы возможностей и текущих ограничений.
- На телефоне надпись о Claude открывается нажатием на заголовок участников.
- Без JavaScript работают ссылки, галерея, нативные `details`; на странице
  установки видны оба способа. Остаются все тексты и фон сцены.
- `prefers-reduced-motion` отключает движения. Canvas-сцены приостанавливаются
  вне экрана и при скрытой вкладке; изменение настройки учитывается сразу.

фрагментами обозначены подписями.

## Обновление

В начале `dist/app.js` находится объект `release`: версия, размер, ссылка на
релиз и IPA. Снимок соответствует проверенному релизу `ios-v0.2.0`.
При обновлении поменяй также подписи и ссылки по умолчанию в HTML для просмотра
без JavaScript. Адрес источника AltStore/SideStore использует `latest`.
Словари обоих языков находятся в `dist/translations.js`.

## Проверка

В Chromium проверены обе страницы на русском и английском при ширинах
320, 390, 768, 1024, 1280 и 1440 px: горизонтальное переполнение, уникальность ID,
якоря и наличие переводов; меню, галерея, буфер обмена, статус-таблица,
участники, установка, FAQ, работа без JavaScript и reduced motion.
Safari и физический iPhone в этой проверке не использовались.

Проверки прошли: обе страницы, меню, порядок блоков главной, мозаика,
участники, статус-таблица, копирование источника, установка, FAQ, словари
и просмотр без JavaScript. Отдельно проверены независимые Canvas-сцены:
остановка вне экрана, изменение reduced motion и возобновление анимации.
Все локальные ресурсы и ссылки на страницы существуют.

Верхний бар имеет подложку на всю ширину экрана, а содержимое — центрированный
контейнер. Мобильное меню разворачивается на высоту экрана. Проверены обе
страницы на ширинах 320–1920 px, закрытие Escape и возврат к настольной ширине.
Участник показан карточкой в стиле оригинала с именем и ролью в iOS-порте.

Плашка спонсора: Dark IPA, реальный аватар Telegram-бота и кнопка с заданной
реферальной ссылкой. URL и реферальная метка в тексте блока не отображаются.
Minecraft-скриншот на фоне сохранён. Проверены оба языка, ширины 320–1440 px,
загрузка круглого аватара, обе ссылки на бота и отсутствие старого поля
AltStore/SideStore в плашке. Источник остаётся доступен на странице установки.
